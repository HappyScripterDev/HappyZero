## Trademark Compliance

Happy Zero has been designed with Ubuntu trademark compliance as a core principle:

1. **No "Ubuntu" in branding** - All product names, logos, wordmarks, and user-facing strings use "Happy Zero" / "HZ".
2. **Complete rebranding** - Custom logos, wallpapers, Plymouth theme, GRUB theme, installer branding, and system identification files.
3. **Removal of Ubuntu assets** - We do not ship Ubuntu logos, Ubuntu-specific branded images, or text containing the word "Ubuntu".
4. **Clear distinction** - Documentation and UI avoid implying endorsement. We state Happy Zero is based on Ubuntu technology but is a separate distribution.
5. **Open source compliance** - We respect all underlying open source licenses (GPL, LGPL, MIT, etc.) of packages and themes we build upon.

## What Changed from Ubuntu

- **os-release / lsb-release**: Identify as "Happy Zero" not "Ubuntu"
- **Boot branding**: Custom GRUB and Plymouth themes
- **Login screen**: Custom GDM branding
- **Wallpapers**: Original HZ wallpapers
- **Installer**: Calamares with HZ branding and custom slides
- **Accent color**: Distinct teal/cyan palette
- **About/identity**: All system identity strings use Happy Zero
